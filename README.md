# Определение ориентации текста: 0° или 180°

Решение предсказывает вероятность `p_180` того, что текст на изображении
перевёрнут на 180°.

## Файлы проекта

- `main.ipynb` — подготовка обучающих данных, обучение CNN и предсказания.
- `predict.ipynb` — предсказания по готовым весам без повторного обучения.
- `artifacts/best_orientation_model_7conv.pt` — веса итоговой модели.
- `req.txt` — версии зависимостей.
- `submission.csv` — итоговые предсказания.

checkpoint с `7conv` -  итоговая модель, которая содержит шесть свёрточных слоёв и 393 858 параметров.

## Подготовка окружения

Использовался Python 3.13.13. Из корня проекта выполните:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r req.txt
python -m ipykernel install --user --name detect-orientation --display-name "detect_orientation"
```

В Windows вместо команды активации используйте:

```powershell
.venv\Scripts\Activate.ps1
```

Откройте блокнот в VS Code с расширением Jupyter или в установленном
Jupyter и выберите ядро `detect_orientation`.
Рабочая директория — корень проекта.

## Входные данные

Разместите предоставленные файлы по следующим путям:

- `test/test/images/` — 20 000 тестовых изображений;
- `test/sample_submission.csv` — образец с колонками `image_id,p_180`.

Для предсказаний также необходим приложенный checkpoint:

- `artifacts/best_orientation_model_7conv.pt`.

## Получение итогового submission.csv

Откройте `predict.ipynb` .

Блокнот загрузит готовые веса, обработает тестовые изображения и сохранит
`submission.csv` в корне проекта. Обучение и загрузка сторонних датасетов
для этого не требуются.

Идентификаторы и порядок строк берутся из `sample_submission.csv`.
Перед сохранением проверяются количество предсказаний и корректность
вероятностей. Используется один проход модели без TTA.

Повторный запуск перезаписывает `submission.csv`.

## Обучение модели

Для обучения с нуля откройте `main.ipynb` и выполните
**Restart Kernel → Run All**.

Для первоначальной загрузки OCR-датасетов GOST, ICDAR2015 и CTW1500
нужен доступ к Hugging Face.

Исходные изображения делятся на train и validation в пропорции 80/20
до создания повёрнутых копий. Для каждого изображения формируются два
примера: исходная ориентация и поворот на 180°.

Модель обучается с CrossEntropyLoss. Лучшие веса выбираются по
максимальному значению `1 − Brier Score` на validation.
Используется early stopping.

Запуск обучения перезаписывает
`artifacts/best_orientation_model_7conv.pt`, а последующие ячейки
сохраняют `submission.csv`. Для воспроизведения приложенного результата
используйте исходные приложенные веса и `predict.ipynb`.

## Результаты и ограничения

Лучший сохранённый validation score итоговой CNN — 0.9123.

Train и validation сформированы из одних внешних источников,
поэтому эта оценка может отличаться от качества на тесте соревнования.
Описание архитектуры, аугментаций и экспериментов приведено в main.ipynb.

## Воспроизводимость

Для разбиения и перемешивания данных используется seed=42.
Перед созданием модели вызывается torch.manual_seed(42).
Версии библиотек указаны в req.txt.

Итоговые предсказания воспроизводятся из приложенных весов через
predict.ipynb. Исходный CSV получен на MPS. Устройство выбирается
автоматически: CUDA, затем MPS, затем CPU. На другом устройстве
возможны небольшие численные различия в вероятностях.
